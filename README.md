Система учёта заявок
1. Назначение
   Система предназначена для регистрации, маршрутизации и контроля исполнения обращений внутри организации.
2. Роли
   - Администратор — управление системой и контроль процесса.
   - Оператор — регистрация заявок и назначение исполнителей.
   - Исполнитель — выполнение назначенных заявок.
   - Заявитель — создание обращений и отслеживание статуса.
3. Функции
   - создание заявки с уникальным номером;
   - назначение исполнителя;
   - статусы: Новая, В работе, Выполнена, Закрыта;
   - категории (не менее 4);
   - комментарии и история изменений;
   - поиск, фильтрация, отчёты.
4. Структура проекта
   - `docs/` — документация: ТЗ, диаграммы, AI-журнал
   - `src/` — исходный код
   - `tests/` — автотесты
5. Документация
   - [Техническое задание](docs/TZ.md)
   - [Диаграмма Use Case](docs/use_case.png)
   
6. Статус проекта
   Текущий этап — лабораторная работа №2 (Git-репозиторий).
   
7. Ветка develop
   Изменение внесено для проверки слияния веток.

Запуск приложения

Требования

- Python 3.10 или выше.

Установка и запуск

1. Склонировать репозиторий: git clone https://github.com/marinamare1/Denisyuk_Marina_ISIP407-307_RequestSystem.git
cd Denisyuk_Marina_ISIP407-307_RequestSystem

2. Убедиться, что база данных создана:
- Файл `docs/database/request_system.db` — существует.
- Если нет — выполнить `docs/database/schema.sql`, затем `docs/database/seed.sql` в DB Browser for SQLite.

3. Запустить приложение: python src/main.py

4. Откроется консольное меню с действиями:
- 1 — показать все заявки;
- 2 — показать заявку по id;
- 3 — создать заявку;
- 4 — редактировать заявку;
- 5 — сменить статус;
- 6 — назначить исполнителя;
- 7 — поиск заявок;
- 8 — фильтр по статусу;
- 9 — удалить заявку;
- 0 — выход.
