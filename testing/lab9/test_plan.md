План тестирования

1. Объект тестирования
Система учёта заявок — REST API и бизнес-логика.
Версия: develop.
Дата тестирования: 11.10.2026.

2. Тестовая среда
- ОС: Windows 10
- Python: 3.12
- FastAPI + uvicorn
- SQLite: docs/database/request_system.db
- Адрес: http://localhost:8000
- Инструмент тестирования: Swagger UI

3. Что проверяется
- Создание заявки с валидацией
- Просмотр списка и одной заявки
- Редактирование заявки
- Смена статуса по цепочке
- Поиск и фильтрация
- Удаление заявки
- Обработка ошибок
- API: успешные и ошибочные запросы

4. Что не входит в проверку
- Аутентификация и авторизация (не реализованы в ЛР №7)
- Нагрузочное тестирование
- Тестирование UI (консольный интерфейс не входит)

5. Виды тестов
- Позитивные функциональные
- Негативные
- Граничные значения
- Интеграционные (API + БД)
- API-тесты

6. Критерии начала
- Приложение запущено: uvicorn src.main_api:app --reload
- Тестовая БД доступна
- Swagger доступен: http://localhost:8000/docs

7. Критерии завершения
- Все 20+ тест-кейсов выполнены
- Дефекты задокументированы
- Результаты зафиксированы скриншотами
