TC-01. Создание заявки с корректными данными
- Цель: проверить создание заявки
- Предусловия: приложение запущено, Swagger открыт 
- Шаги:
  1. Открыть POST /requests                     
  2. Ввести корректные данные                      
  3. Нажать Execute
- Входные данные:  
{
    "topic": "Тестовая заявка", 
    "description": "Описание", 
    "category_id": 1, 
    "priority": "Средний", 
    "requester_id": 4
} 
- Ожидаемый результат: HTTP 201, заявка создана, есть id 
- Фактический результат: HTTP 201, id = 15
- Статус: PASS
- Доказательство: [тс-01](testing\lab9)
